ไมค์บางตัว (โดยเฉพาะเว็บแคม) ตัดความถี่สูงทิ้ง จนไม่ได้ยินย่าน ~17.5 kHz — ถ้าถอดรหัสไม่ได้ ลองอัดเป็นไฟล์แล้วเปิดสเปกตรัมดูว่ามีสัญญาณแถว 17.5 kHz ไหม

02Conversation · จำลอง Furby 2 ตัวคุยกัน

  

    ข้อจำกัดที่ควรรู้: โปรโตคอลเสียงรุ่น 2012 นี้ไม่มีการ "จับคู่"/เช็กชื่อ-สี-รุ่นแบบแอป Furby Connect (Bluetooth, รุ่น 2016) —
    Furby ตัวไหนได้ยินก็ตอบสนองหมด ไม่มีการระบุตัวตนผู้ส่ง ส่วนที่เป็นของจริงจาก Command.pm คือคำสั่ง 813 (ถามบุคลิก → ตอบ 900-905)
    และ event 883/884 (ชอบ/ไม่ชอบอาหาร) ส่วน "สมอง" ที่ตัดสินใจว่าจะตอบอะไร (มู้ด, หลับ, สุ่มชอบ/ไม่ชอบ) เป็นตรรกะจำลองที่ผมเขียนเอง ไม่ใช่ของที่ reverse-engineer มา
    เพราะไม่มีข้อมูลสาธารณะว่า Furby ตัดสินใจภายในอย่างไร
